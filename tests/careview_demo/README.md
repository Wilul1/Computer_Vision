# CareView demo pack

Exactly two patients after wipe / **Reset demo**:

| Patient | Room | Source | What you get |
|---------|------|--------|----------------|
| **Alex** | Room 01 | Live Camera Station (`p1-ana`) | Empty until `/camera-station` starts |
| **Casey** | Room 14 | Fall clip (pre-analyzed) | Alerts + session + playback already ready |

## How to use

1. Start the app → open `/caregiver` (first boot prepares Casey; can take ~1 min)
2. Home should show **Alex** + **Casey** (Casey may already be ALERT)
3. Open **Casey** / **Alerts** — no need to Run room check first
4. On the laptop, open `/camera-station` for **Alex** live monitoring

Settings → **Reset demo** re-wipes and re-prepares Casey.
